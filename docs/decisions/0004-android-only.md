# 0004 v1 只做 Android（Kotlin + Compose）

- 状态：已接受
- 日期：2026-11-07

## 决策

v1 只做 Android 客户端，使用 Kotlin + Jetpack Compose 原生开发，minSdk 26（Android 8.0）。

## 理由

- Android 允许前台服务在后台保持连接，没有服务器也能发出本地通知；iOS 做不到这一点。
- 可以直接分发 APK，不受应用商店审核限制。
- 不需要跨平台框架，技术栈更简单。
- minSdk 26 和同类项目保持一致，能覆盖绝大多数设备。

## 代价 / 后果

- iPhone 用户暂时无法使用。
- 部分国产手机的省电策略可能会杀掉前台服务，需要引导用户把 App 加入电池优化白名单。
- 以后如果要支持 iOS，必须有服务器负责发推送，这与 0001 有关。
