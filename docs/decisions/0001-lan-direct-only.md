# 0001 v1 只做直连，网络由用户解决

- 状态：已接受
- 日期：2026-11-07

## 背景

现有的远程方案主要有两类：一类依赖第三方组网工具（Tailscale 等），另一类自建账号系统和中转服务器（ds-harness-remote）。前者把项目和某个第三方工具绑在一起；后者需要长期运营服务器，用户还要信任这台服务器。

## 决策

v1 只做 App 到插件的**直连**。App 只需要一个能连通的地址和端口，至于怎么连通（同一 Wi-Fi、Tailscale、ZeroTier、VPN），由用户自己解决。项目本身不依赖、也不集成任何组网工具。

## 理由

- 结构最简单，不需要运营任何服务器。
- 用户的数据不经过任何第三方。
- Tailscale 等工具本质上也是提供一条可连通的网络，用户自行配置即可，项目无需绑定。

## 代价 / 后果

- 不在同一网络、也没有配置 VPN 时无法连接。App 需要把「连不上」的原因提示清楚。
- 没有服务器就没有云推送，App 在后台时只能靠前台服务接收通知。
- 以后如果要加中转服务器，应该作为一种新的「传输方式」接入，配对、加密、界面都不需要改。设计时要把传输层做成可以替换的一层。
