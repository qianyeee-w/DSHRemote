# 0003 加密始终开启，不提供关闭选项

- 状态：已接受
- 日期：2026-11-07

## 背景

用户通过 Tailscale 连接时，流量已经被 WireGuard 加密，App 再加一层加密在技术上是重复的。所以有人会想提供一个「在可信网络下关闭加密」的选项。

## 决策

加密始终开启，不提供关闭选项。插件的局域网端口只提供 TLS。

## 理由

- App 无法判断用户当前的网络是否可信：`100.x` 可能是 Tailscale，`192.168.x` 可能是咖啡馆的公共 Wi-Fi。
- 即使流量已经加密，「谁可以操作这台电脑上的 DSH」这个认证问题仍然要自己解决，加密通道可以在认证时一并建立。
- 只维护一条代码路径，更简单，也更不容易出错。
- Android 9 起默认禁止明文 HTTP。
- 在现在的手机上，TLS 的性能开销可以忽略。

## 代价 / 后果

- 使用 Tailscale 时会有两层加密，但开销很小。
