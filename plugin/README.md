# DSHRemote 电脑端插件

让 Android 手机上的 DSHRemote App 通过局域网操控这台电脑上的 DeepSeek Harness：查看会话、发送消息、处理审批和提问、接收通知。

- 手机和插件之间只用 HTTPS / WSS。手机配对时记下插件的证书指纹，以后每次连接都会核对。
- 只有扫码配对过的手机才能访问。在配对页上可以随时撤销某台手机。
- 插件只提供 App 需要的操作，不转发其他 DSH 接口。

## 安装和升级

1. 下载 `dshremote-plugin-<版本>.tgz`，**放到一个固定的文件夹里，不要删除或移动它**。DSH 以后安装或更新其他插件时还会读取这个文件。
2. 在 DeepSeek Harness 的「插件」→「添加插件」中，填入这个文件的**完整路径**，然后点「安装」。
3. 第一次安装后，浏览器会自动打开配对页（`http://127.0.0.1:3191`），用手机 App 扫描页面上的二维码。

升级：按同样的步骤安装新版本的 `.tgz`，也可以先卸载旧版本再安装。证书和已配对的手机都会保留，不需要重新配对。新版本装好后，旧版本的 `.tgz` 可以删除。

## 配置

一般不需要修改。如果端口被其他程序占用，可以在 profile 的 `cordis.patch.yml` 中替换整行配置（DSH 会整行替换 `config`，所以要写全所有键）：

```yaml
- id: dshremote
  name: dshremote
  config:
    enabled: true
    lanPort: 3190            # 局域网 HTTPS 端口，手机连接这个端口
    lanBind: 0.0.0.0         # 监听地址，0.0.0.0 表示所有网卡
    adminPort: 3191          # 本机配对页的端口，只监听 127.0.0.1
    openAdminOnFirstRun: true
```

端口被占用时，插件在 DSH 的插件列表中显示为失败，并说明是哪个端口。

## 数据

证书、私钥和已配对设备保存在 DSH 数据目录（默认 `~/.dsh`）下的 `dshremote/` 中，和插件安装在哪里无关。卸载或升级插件不会删除这些数据；要彻底清除，卸载插件后手动删除这个文件夹。删除后所有手机都要重新配对。
