# 字体来源与许可证

字体全部使用 SIL Open Font License 1.1，许可证随 APK 放在 `assets/font-licenses`。字体作为本地资源使用，不发起字体下载请求。

- **界面和正文**：IBM Plex Sans SC 1.1.0，取自 IBM/plex 仓库标签 `@ibm/plex-sans-sc@1.1.0` 下的 `fonts/complete/ttf/hinted`，和同一标签的发布包 `ibm-plex-sans-sc.zip` 是同一批文件。没有裁剪或修改；许可证保留字体名「Plex」，所以改动过的文件不能再叫 Plex。
- **代码**：JetBrains Mono，取自 Google Fonts 官方分发（v24）。设计只用 400 和 600 两个字重。
