# 0005 DSH 基线 0.2.2-rc.1，只用公开接口

- 状态：已接受
- 日期：2026-11-07

## 背景

DSH 还处在开发者预览阶段，接口可能随时变化。社区里有些插件为了实现功能，直接修改了 DSH 的内部字段，例如在运行时改 `trustedHosts`、把 cookie 有效期延长到 10 年，这些做法在 DSH 升级后很容易失效，还会削弱 DSH 原有的安全设置。

## 决策

- 适配基线是 DSH `0.2.2-rc.1`。插件的 `engines.dsh` 写成 `>=0.2.2-rc.1 <0.3.0-0`。
- 只使用 DSH 公开的服务接口，例如 `ctx.webServer.port`、`ctx.connection.authenticatedUrl()`。
- 不修改 DSH 的任何内部字段，DSH 自己的 Host / Origin 校验、cookie 有效期等安全设置一律保持原样。

## 理由

- DSH 升级时，项目更不容易被破坏。
- 不削弱 DSH 自身的安全设置。

## 代价 / 后果

- 有些功能用公开接口实现起来更麻烦，比如要自己做转发和请求头改写，而不能直接改配置。
- 升级基线版本必须单独提交，并在 decisions 中新写一条记录。
