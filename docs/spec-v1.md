# 第一版功能范围（v1）

目标：在**同一局域网**（或用户自行配置的 Tailscale / VPN）下，用 Android 手机完整跑完一个 DSH 任务：发起任务、看进度、处理审批和提问，Agent 需要你时收到通知。

本文件里的功能分三档：**必须有**、**第二版**、**以后再说**。不在「必须有」里的功能，v1 一律不做。

## 必须有（v1）

### 电脑端插件
- [ ] 在局域网固定端口（默认 `3190`，可配置）提供 HTTPS / WSS 服务
- [ ] 首次运行生成自签名证书（ECDSA P-256），证书指纹固定
- [ ] 本机配对页：显示二维码（地址、端口、证书指纹、一次性配对码）和已配对设备列表，可撤销设备
- [ ] 配对接口：一次性配对码换取设备 token；配对码 5 分钟内有效，用后作废，限制尝试次数
- [ ] 所有接口校验设备 token（`docs/protocol.md` 中标注为「无需认证」的除外）
- [ ] 读取 DSH 当前端口，持有 DSH 官方会话，把请求转发给 DSH
- [ ] 启动时检查 DSH 版本，不兼容时明确报错
- [ ] 支持 Windows 和 Linux（v1 不适配 macOS，见 ADR 0006）

### Android App

**连接**
- [ ] 扫码配对；扫不了码时可手动输入地址、端口、配对码
- [ ] 证书指纹固定：指纹不匹配直接拒绝连接，提示用户重新配对
- [ ] 保存多台主机，在列表中显示每台主机的在线状态
- [ ] 断线后自动重连，网络变化后自动恢复

**会话**
- [ ] 会话列表：显示状态（运行中 / 等待你处理 / 空闲），等待处理的排在最前
- [ ] 新建会话（选择工作区）
- [ ] 会话详情：流式输出、Markdown 渲染
- [ ] 工具调用以卡片显示，默认折叠，点开查看参数和结果
- [ ] 思考过程默认折叠
- [ ] 历史记录分页加载：先显示最近几条，往上滚动再加载更早的

**操作**
- [ ] 发送消息；Agent 运行中也能插话
- [ ] 停止当前任务
- [ ] 审批：允许 / 拒绝（DSH 的审批只对当前这个请求有效，没有「以后都允许」，见调研文档 5.3）
- [ ] 回答提问：单选、多选、文本
- [ ] 切换模型和权限模式（权限模式用于减少审批次数）
- [ ] 一个审批在手机和 Desktop 上同时出现时，任意一端处理后，另一端自动收起

**通知**
- [ ] 前台服务保持与已连接主机的连接
- [ ] 需要审批或回答提问时：立即发出高优先级通知，相同事件去重
- [ ] 任务完成时：会话持续空闲一小段时间（暂定 8 秒）后再通知，避免误报
- [ ] 点通知直接打开对应会话
- [ ] Android 13 及以上首次启动时申请通知权限；引导用户把 App 加入电池优化白名单

**设置**
- [ ] 管理主机：重命名、删除、重新配对
- [ ] 通知开关

## 第二版

用户已确认优先实现「创建／导入项目」：手机浏览电脑目录、创建单个项目文件夹或登记已有目录，然后在该工作区开始会话。它是 v1 基础完成后的独立扩展，方案见 [`plans/project-create-import.md`](plans/project-create-import.md)，不同时纳入完整文件管理或终端。

- 图片附件
- 计划 / 目标视图
- 执行轨迹和用量统计
- 在通知里直接审批（「允许」「拒绝」按钮）
- 中英文界面
- 局域网自动发现（mDNS）
- 在 DSH Desktop 设置页内显示配对二维码（替代本机配对页）

## 验收场景

v1 完成的标志是下面这个场景能在真机上走通：

1. 电脑上安装插件并启动 DSH，用浏览器打开本机配对页。
2. 手机扫码完成配对。
3. 在手机上新建会话，让 Agent 修改一个文件。
4. 锁屏，Agent 请求审批时手机收到通知；点通知后在手机上批准。
5. 任务完成时手机收到通知，打开后能看到完整结果。
6. 重启电脑上的 DSH（端口会变），手机自动重连，不需要重新配对。
7. 在配对页撤销这台手机后，手机立刻无法再连接。
