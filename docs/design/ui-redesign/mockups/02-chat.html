通知里同一个审批会重复出现，帮我查一下原因并修掉。

找到原因了。同一个审批会从两条路径进来，去重用的键不一样：建立连接时按主机加事项编号，收到新事件时只按事项编号。

我把两处统一成 key() 一个入口：

NotificationRules.kt
private fun key(hostId: String, item: Attention) = "$hostId/${item.id}" fun onAttention(hostId: String, item: Attention) { if (!seen.add(key(hostId, item))) return notifier.post(hostId, item) }
