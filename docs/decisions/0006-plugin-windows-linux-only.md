# 0006 v1 插件只适配 Windows 和 Linux

- 状态：已接受
- 日期：2026-11-07

## 决策

v1 的电脑端插件只适配 Windows 和 Linux，不适配 macOS。

## 理由

- 集中精力在实际使用的平台上，减少测试和排查问题的范围。

## 代价 / 后果

- macOS 用户暂时无法使用。
- 编写插件代码时仍应使用 Node 的跨平台 API（例如用 `path.join` 拼接路径，不硬编码路径分隔符），不要故意写成只能在某个平台上运行。以后适配 macOS 时，主要工作应当只是测试和补齐少数平台相关的细节。
- CI 只在 Windows 和 Linux 上运行插件测试。
